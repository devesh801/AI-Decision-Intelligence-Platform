---

## 📖 Overview

Machine Learning projects often require repetitive tasks such as:

- Data Profiling
- Data Cleaning
- Missing Value Handling
- Model Selection
- Model Training
- Performance Comparison

Similarly, research requires collecting, organizing, reviewing, and summarizing information.

This project combines both into a single intelligent platform.

Users can:

- 📊 Upload datasets
- 🤖 Automatically train multiple ML models
- 📑 Generate AI-powered research reports
- 📈 Compare model performance
- 🎯 Predict on new data
- 🧠 Generate AI Decision Reports
